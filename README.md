### Showcase your projects. Get real feedback. Level up as a developer.

## 📌 Overview

**DevReview** is a full-stack developer community platform where developers can showcase their projects, receive peer feedback, connect with other developers, and build a strong public portfolio.

The platform is designed around project discovery, reviews, developer networking, messaging, and community engagement.

---

## ✨ Core Features

| Feature | Description |
|---|---|
| 🔐 **Authentication** | Secure user authentication with email verification and Google sign-in |
| 📁 **Project Showcase** | Create, edit, and showcase projects with tech stacks, images, live demos, and repository links |
| ⭐ **Reviews & Ratings** | Give and receive constructive project reviews and ratings |
| 💬 **Direct Messaging** | One-to-one conversations between developers |
| 🔔 **Notifications** | Stay updated with reviews, messages, follows, and other interactions |
| 🏆 **Leaderboard** | Discover top developers and highly-rated projects |
| 👤 **Developer Profiles** | Public developer profiles with bio, skills, social links, and projects |
| 🧑‍🤝‍🧑 **Follow System** | Follow developers and grow your network |
| ❤️ **Likes & Bookmarks** | Like projects and save them for later |
| 🔎 **Search & Discovery** | Discover developers and projects through search, filters, and sorting |
| 📊 **Dashboard** | Track personal activity, projects, reviews, followers, and other community statistics |
| 🌓 **Responsive UI** | Modern responsive interface with light and dark themes |

## 🔒 Security Practices

* **HTTP-Only Cookies**: JWT authentication uses HTTP-only cookies.
* **Rate Limiting**: Critical authentication and API endpoints are protected against abuse.
* **Password Hashing**: User passwords are securely hashed before storage.
* **OTP Verification**: Email ownership is verified through OTP-based authentication.
